# 断板反包扫描误判根因修复记录（2026-08-12）

> 触发：用户发送利柏特/联创电子同花顺截图，质疑"为什么这次还是不准"。
> 通过"截图OCR → 实时行情匹配 → K线逐日核验"三通道复现了完整误判链条。

## 误判一：利柏特 605167（一字板+连板被当首板）

### 真实形态（数据核验）
```
8/3  一字板 开14.38 收14.40 振幅0.14% 量0.44×均量   ← 被误判为"首板"
8/4  又一字板 +10%                                    ← 二连板加速，未被识别
8/5  天地板 开17.25 收15.87 振幅15.9% pct=+0.19%(假阳) ← 真断板日，被跳过
8/6  -6.3% 普通回落 量=6.67×首板                       ← 被误判为"洗盘日"
8/7~ 横盘 → 判定"护盘" → 买点A
```

### 根本原因（4层）
1. **一字板被当作"首板"**：扫描只要求涨幅≥6.7%+前3日无涨停+量<3×20日均量。
   一字板（开盘即封板、无分歧无换手）全满足 → 但一字板主力无法收集筹码，
   不构成"横盘吸筹→异动首板"的战法语义。
2. **首板后连板未排除**：原逻辑只排除"首板前3日涨停"，漏掉"首板后1-2日又涨停"
   （8/4 二连板）。断板反包只做首板后的首次断板，连板加速后的天地板=情绪顶点出货。
3. **wash_vol_ratio=6.67 是数学假象**：分母是8/3一字板的量（几乎无量），
   任何后续放量都必然≥1.5×首板量 → 洗盘条件恒真。
4. **天地板假阳线被跳过**：8/5 开17.25收15.87，相对昨收 pct=+0.19%（假阳），
   原判定 `pct<-3%` 不通过 → 真断板日被跳过，8/6 普通回落被误当洗盘日，
   时间轴错位一天，支撑/护盘判定全部基于错误锚点。

### 修复①：一字板/秒板剔除
- 判定：振幅<1% 且 开=高 → 剔除（开盘即封板，无洗盘前提）
- 位置：`analyze_stock()` 首板候选循环内

### 修复②：首板后1-2日连板排除
- 判定：首板后1-2个交易日内 pct≥9.5% → 连板加速，剔除
- 位置：同上

### 修复②b：洗盘日必须实体阴线
- 判定：`close<open`（实体阴线）+ (实体跌幅>3% 或 振幅>10%天地板) + 放量≥1.5×首板量 + ≥1×MA5
- 根因：利柏特 8/5 天地板 pct=+0.19% 假阳线被跳过；8/6 普通回落被误当洗盘
- 位置：`analyze_stock()` 洗盘识别 + 补识别分支 + `check_optimized_a()` 洗盘定位

## 误判二：联创电子 002036（收盘破位仍判买点A）

### 真实形态（数据核验）
```
8/5  首板 开7.32 收7.80 +10% 正常涨停（非一字板）
8/6  洗盘 -4.5% 实体阴 量2.7×首板 ✅ 正常
8/7  收7.29 < 首板开盘7.32 ← 收盘开始破位
8/10 收7.31 < 7.32
8/11 收7.21 < 7.32
8/12 收7.25 < 7.32 ← 连续4日收盘破位，仍被判"买点A"
```

### 根本原因
- 破位判定用 `support = first_open × 0.97`（3%容忍）：
  7.32×0.97=7.10，收盘7.25>7.10 → 判定"未破位"。
- 但手册铁律是**无容忍**："首板开盘价=主力成本底线，一旦收盘有效跌破，
  视为形态失败，立即剔除"。0.97容忍线稀释了铁律。

### 修复③：破位判定回归铁律
- 破位判定：`close < first_open`（不用0.97容忍线）
- 回踩判定（touching）：`close >= first_open`（买点A必须收盘站上首板开盘价）
- 0.97容忍线保留为 `support` 字段（盘中刺穿容差参考），但不参与破位/买点判定

### 修复⑤：二波异动排除（用户再核验触发）
- 根因：联创电子 8/5 涨停被当"首板"，但前20日已有 7/20-21 两连板
  → 8/5 实为**第二波异动**（第一波见顶回落后的再启动），不是"横盘吸筹→首次异动"
- 二波异动的洗盘/护盘逻辑不同：第一波套牢盘密集，反包难度大，不符合战法前提
- 判定：首板前20个交易日内存在 pct≥9% 的涨停 → 剔除

## 教训（写进 memory）

1. **手册字面经验值 vs 数据验证判据**：只有数据验证过的判据才能做硬过滤，
   手册经验值（如"首板成交额≈流通市值1%"）只能参考。但反过来——
   **手册铁律（首板开盘价破位）也是数据验证过的核心因子，不能被实现细节稀释**。
2. **一字板是特殊形态**：开盘即封板=无换手无分歧，任何基于"量比"的判定
   在分母≈0时都会失真。首板必须排除一字板。
3. **pct 口径陷阱**：`pct = close/close_prev - 1` 无法识别"天地板假阳线"
   （开涨停收平盘，相对昨收+0.19%但实体是巨阴）。洗盘/断板判定必须看实体方向。
4. **用户截图核验是最高效的 bug 发现通道**：真实K线图暴露的形态错误，
   比任何回测指标都直接。修复后必须用真实数据回归验证（不是只跑单测）。
