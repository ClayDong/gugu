# 领域约定规范（单一事实源）

> 本文件是 A 股领域约定的**唯一权威来源**。所有代码、review、测试以此为对照基准。
> 任何 UI 颜色、通知 emoji、涨跌语义的改动必须先改这里，再改代码，并同步契约测试
> `tests/unit/test_presentation_contract.py`。
> 违反本文件的代码一律视为缺陷（即使逻辑自洽）。

## 1. 颜色语义（A 股约定：红涨绿跌）

| 语义 | 颜色 | 色值（Web UI） | 禁止 |
|------|------|----------------|------|
| 涨 / 盈利 / 上涨 | 🔴 红 | `#f85149` (positive) | ❌ 绿 |
| 跌 / 亏损 / 下跌 | 🟢 绿 | `#3fb950` (negative) | ❌ 红 |
| 买入 / 资金流入 | 🔴 红 | `#f85149` (signal-dir-buy) | ❌ 绿 |
| 卖出 / 资金流出 | 🟢 绿 | `#3fb950` (signal-dir-sell) | ❌ 红 |
| 净流入（资金流文案 emoji） | 🔴 红 | — | ❌ 绿 |
| 净流出（资金流文案 emoji） | 🟢 绿 | — | ❌ 红 |

**与美股约定的区别**：美股绿涨红跌；A 股（沪深交易所、同花顺、东方财富等主流软件）一律红涨绿跌。本项目服务 A 股，必须用 A 股约定。

## 2. 方向色与状态色分离

不是所有红色都表示"涨"。两类语义严格分离，不得混用：

- **方向色**（本文件第 1 节）：表达涨跌/买卖/资金方向，红涨绿跌。
- **状态色**：表达运行状态好坏，通用告警约定（红=危险，绿=正常）：
  - 风控正常 = 绿 `#3fb950`；熔断/危险 = 红 `#f85149`；过滤/暂停 = 黄 `#d29922`
  - 测试通过 ✓ = 绿；测试失败 ✗ = 红；数据质量徽章（🟢 实时 / 🔴 非实时）
  - 告警等级 emoji（🔴 严重告警 / 🟢 普通扫描）属于状态色，不表示方向

判断标准：如果该处颜色/emoji 表达的是"事情好不好"→ 状态色；表达"市场方向/资金方向" → 方向色。

## 3. 单位约定

| 量 | 单位 | 说明 |
|----|------|------|
| 个股/行业资金流（main_net、super_large_net） | 亿元 | 数据源已转换，代码内不再 /1e8 |
| 大盘资金流 | 亿元 | |
| 个股价格、持仓市值、账户资产 | 元 | 展示时格式化（如 ¥12,345.67） |
| 百分比字段（main_pct、change_pct、profit_ratio 除外） | % 数值本身 | 5.0 表示 5% |
| profit_ratio | 小数 | 0.05 表示 5%，展示时 ×100 |

## 4. 交易时段

- A 股连续竞价：09:30–11:30，13:00–15:00（工作日，节假日休市）
- 交易日历以 `gugu/utils/calendar.py` 为准（含节假日表 + 交易日计算）
- 任何"自然日"用于交易日判断的写法都是缺陷（参考 P1-2 长假缓存误删）

## 5. 呈现完整性契约

API 返回给用户的每个业务字段，凡用户需要阅读的，必须有对应 UI/通知呈现。
典型反例（已修复）：`/api/portfolio` 返回 `market_value` 但持仓表无市值列。

## 6. 字符编码红线

- 源码一律 UTF-8；🔴🟢⚠️ 等 emoji 为 3–4 字节 UTF-8 序列
- **禁止**任何工具以非 UTF-8 或 UTF-16 中转读写源码（会把 4 字节 emoji 损坏为 U+FFFD）
- 契约测试 `test_presentation_contract.py` 全仓库扫描 U+FFFD，出现即构建失败

## 7. Review 强制环节（用户视角终审）

任何 UI / 通知文案 / 颜色类变更，review 必须包含：

1. 对照本文件逐条核对约定
2. 实际运行服务并查看渲染结果（curl 或浏览器截图），不允许只读代码
3. 终审提问："我不是在审代码，我是在审用户看到的东西——用户会看到什么？"
