## 一、我是谁

**散户。** 不是机构，不是量化，不是游资。

我的优势：
- 可以空仓。机构有仓位下限，我没有。
- 可以只做一只。机构要分散，我可以集中火力。
- 可以等。没有赎回压力，没有排名焦虑。
- 船小好调头。100万以下的资金，进出不影响盘面。

我的劣势：
- 没有信息优势。机构有调研团队，我没有。
- 没有速度优势。量化在毫秒级交易，我拼不过。
- 没有资金优势。不能像游资一样封板。

**所以我的策略是：不拼速度、不拼信息、不拼资金。拼耐心、拼纪律、拼聚焦。**

## 二、我的道

> 截断亏损，让利润奔跑。顺势而不预测。耐心等待，只在胜率最高时出手。

### 四条铁律

| 道 | 规则 | 代码实现 |
|-----|------|---------|
| **顺势不预测** | 不预判大盘，做跟随者。RegimeDetector 定方向。 | `regime_detector.py` |
| **截断亏损** | 每笔交易入场前知道止损价。移动止损 8%。 | `base.py:_apply_trailing_stop_exit` |
| **让利润奔跑** | 赚钱的仓位不设时间上限。从最高点回撤才卖。 | 同上 |
| **耐心等待** | 80% 时间空仓或观察。冰点才出手，涨停稀少时空仓。 | `market_env.py` + `_entry_gate` |

### 钱多多的道

> 有总龙头，就不要做分龙头。有连板的龙头，就不要做反包的龙头。
> 有主升的龙头，就不要做反抽的龙头。有主线的龙头，就不要做支线的龙头。
> 有市场选出的龙头，就不要做自己选的龙头。

> 个股先于情绪，情绪先于板块，板块先于大盘。

> 不要预判大盘，做大盘的跟随者。

> 每天只有几只涨停板，那就空仓等机会。
> 冰点极致，买在不得不涨的时间窗口，买入引领上涨的核心焦点。

## 三、我的术

### 市场环境判断（每日第一件事）

```
打开 gugu → 查看 MarketEnvironment 输出：
  ├── 涨停数 < 5 只 → 冰点/空仓模式
  │   └── 冰点极致 → 关注率先涨停的焦点股（试探性买入）
  ├── 涨停数 5-20 只 → 谨慎模式
  │   └── 只做确定性最高的信号
  └── 涨停数 > 20 只 → 正常模式
      ├── 封板率 > 70% → 可以打板（huamulan_ghost_breakout）
      ├── 接力率 > 60% → 可以接力（dragon_head）
      └── 其他策略正常执行
```

### 策略矩阵（10 个策略，按市场状态分流）

| 市场状态 | 启用策略 | 说明 |
|---------|---------|------|
| **冰点** | sentiment_cycle（冰点买入） | 恐惧→试探性买入 |
| **正常/牛市** | sector_momentum, dragon_head, box_breakout | 趋势+龙头+动量 |
| **正常/震荡** | double_yin, rsi_reversal, linjudaye | 回调+反转+多规则 |
| **正常/反弹** | huamulan_ghost_breakout, price_volume_signal | 打板+资金流 |
| **所有** | regime_cycle_four | 周期择时 |
| **熊市/崩盘** | 空仓 | 不买任何股票 |

### 入场五关（每笔买入必过）

```
买入信号 → ☐ 1. 市场状态允许？（bear/crash 禁止）
          → ☐ 2. 风控未熔断？
          → ☐ 3. 持仓数 < 上限？
          → ☐ 4. 今日非剧烈波动（>5%）？
          → ☐ 5. 涨停环境允许？（涨停稀少→空仓；封板率低→不打板；接力率低→不接力）
          → 全部通过 → 执行
          → 任一不通过 → observation_only（观察但不执行）
```

### 出场规则

```
买入后：
  ├── 追踪持仓期间最高价
  ├── 回撤 8% → 无条件卖出（移动止损）
  ├── 跌破 MA5 且收阴 → 卖出
  └── 不设时间上限（让利润奔跑）
```

## 五、每日流程

### 盘前（09:00-09:25）

1. 打开飞书，查看 gugu 的盘前推送
2. 查看 `MarketEnvironment` 评估：
   - 今天是什么环境？冰点/正常/空仓？
   - 封板率多少？接力率多少？
   - 今天能打板吗？能接力吗？
3. 确定今天的操作模式：**进攻/防守/空仓**

### 盘中（09:30-15:00）

1. gugu 自动扫描，推送信号到飞书群
2. 收到信号后，手动确认：
   - 信号是否通过了入场五关？
   - 是否符合今天的操作模式？
   - 如果不符合，为什么？记入交易日志
3. **不盯盘。** gugu 扫描 + 飞书推送，不需要时刻盯着。

### 盘后（15:00-16:00）

1. 查看 `data/trade_journal.jsonl` 今日记录
2. 复盘问题：
   - 今天有哪些信号？哪些被拦截了？为什么？
   - 哪些策略产生了信号？信号质量如何？
   - 有没有该做但没做的？有没有不该做但做了的？
3. 记录复盘笔记

### 周末（每周日）

1. 查看本周所有交易日志
2. 统计：
   - 总信号数 / 拦截数 / 执行数
   - 各策略信号分布
   - 盈亏情况（模拟盘）
3. 调整：
   - 哪些策略在亏钱？为什么？
   - 市场环境在变化吗？需要调整策略权重吗？
   - 入场 Gate 有没有该拦没拦的？

## 六、我的拼图

钱多多说：**复盘不是预判未来，是在未来出现的时候，你能更快做出动作。**

这些是我要积累的拼图：

| 拼图 | 场景 | 动作 |
|------|------|------|
| 同盘共振 | 大盘补缺口瞬间，出现涨停 | 关注率先涨停股 |
| 次新轮动 | 大盘低迷，板块轮动 | 次新股可能有表现 |
| 卡位龙 | 龙头上升乏力，板块未结束 | 关注卡位龙 |
| 老龙回光返照 | 混沌期，老龙垂死 | 关注回光返照 |
| 冰点极致 | 涨停板极少，情绪极度恐惧 | 试探性买入焦点股 |
| 情绪退潮 | 中军无力，跟随龙不涨停 | 撤退 |

每发现一块拼图，就记下来。日积月累，拼图完整的那一天，就是你悟道的那一天。

## 八、诚实自省

> 你不需要用预判来吸引别人的关注。如果你这样做了，哪怕连续对了几次，换来的也只不过是沾沾自喜。但你错了一次，就会遭受被打回原形的重创。而所有的预判都不可能全对。
> —— 钱多多

**当前系统没有验证过的赚钱策略。** 模拟盘正在跑，10 个策略在观察中。不要因为回测好看就自信，不要因为连续对了几次就膨胀。保持空仓的能力，保持等待的耐心，保持对市场的敬畏。

**这条路很长，但方向是对的。**
