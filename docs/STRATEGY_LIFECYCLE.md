# 策略生命周期规范（Strategy Lifecycle）

> 版本：v1.0.0
> 日期：2026-08-15
> 定位：gugu 项目所有策略从"诞生"到"上线"的统一方法论，是策略工厂的流水线骨架。

---

## 一、为什么需要这份规范

断板反包战法的完整证伪过程（2026-07-31 事件研究 → 2026-08-01 Walk-Forward 证伪 → 2026-08-12 截图核验修复）暴露了三个反复出现的坑：

1. **小样本 + 牛市 beta + 幸存者偏差**，让一个负期望形态看起来能赚（声称 9:1，实测 5日超额 -1.5%）。
2. **前视偏差**让视觉评分从 V1 +5.95% 翻案成 V2 -0.57%。
3. **规则内部矛盾 + 实现漂移**，同一战法在扫描/回测/策略三处实现三个版本。

这份规范把这些教训固化成**每个策略都必须走过的关卡**，而不是某一次性的踩坑记录。

## 二、三层架构

```
┌─────────────────────────────────────────────────────────┐
│ ③ LLM 辅助层 —— 不决策                                    │
│    规则提取 · 信号审计(截图核验) · 复盘解释 · 假设生成      │
├─────────────────────────────────────────────────────────┤
│ ② 决策层 —— 数据当裁判                                    │
│    只跑 Walk-Forward 验证过的规则                         │
│    未通过 = 永不启用；通过 = conditional_pass 观察         │
├─────────────────────────────────────────────────────────┤
│ ① 认知资产层 —— 从任何策略抢救出的、被数据验证的通用因子     │
│    活跃度过滤 · 破位止损 · 板上减半止盈（见 risk_rules.py） │
└─────────────────────────────────────────────────────────┘
```

**核心原则八个字：数据裁判、规则执行、LLM 审计、人拍板。**

### ① 认知资产层
策略验证失败 ≠ 全盘否定。每个策略都可能留下**被数据验证有效的独立规则**，拆解成通用组件供全项目复用。断板反包留下的三条已落地为 `src/gugu/strategies/risk_rules.py`：

| 资产 | 函数 | 验证来源 |
|------|------|---------|
| 活跃度过滤（历史涨停≥N 的妖股池） | `count_limit_ups` | 低活跃 -5.6% → 高活跃打平（唯一正收益分层） |
| 位置分位（相对低位 vs 上涨后） | `position_percentile` | 手册"位置"维度，排除上涨后追高 |
| 破位止损（收盘破支撑价即走） | `apply_support_break_stop` | 手册铁律，数据验证有效 |
| 板上减半止盈（放量反包先锁利） | `detect_lock_profit_days` | 盈亏比思维，TP1 |

### ② 决策层
决策只能建立在**可证伪的正期望**上。判断权在数据，不在 prompt、不在盘感、不在"我觉得"。

### ③ LLM 辅助层
LLM 的正确位置是**提取、审计、复盘、提假设**，唯独不碰决策。原因：LLM 看图自带前视偏差（已看到右边结果）、不可回测、无实盘盘感、会事后合理化。

## 三、证伪三件套（每个策略上线前的强制关卡）

### 关卡 1：前视偏差审计
- 静态扫描：策略代码禁止 `shift(-n)`、禁止引用未来索引。
- 铁律：**信号与特征必须在"信号时刻"可得**。
- 反面教材：断板反包视觉评分 V1 用事后特征 +5.95%，去前视后 V2 -0.57%。

### 关卡 2：Walk-Forward 样本外检验
- 事件研究（in-sample）的漂亮数字**不等于**可交易 edge。
- 必须做滚动样本外检验，全年份负超额 = 证伪。
- 反面教材：rebound_elite in-sample 10日 +9.99%（16 样本），Walk-Forward 43 信号 -5.40% p=0.035 显著为负。

### 关卡 3：真实数据核验
- 单元测试通过 ≠ 形态正确。必须用真实 K 线截图逐日核验。
- 反面教材：利柏特一字板当首板、联创电子天地板假阳、破位容忍线稀释铁律，全是截图核验揪出来的。

## 四、上线门槛状态机

每个策略在 `config/strategy_manifest.yaml` 的 `validation_gate.status` 上按此流转：

```
pending ──回测──▶ backtest_failed（证伪，永不启用）
   │
   └──样本外通过──▶ conditional_pass（有条件通过）
                      │
                      ├─ 实盘前向验证 30+ 信号复验 p 值
                      │       │
                      │       ├─ 通过 ──▶ enabled（正式启用）
                      │       └─ 失败 ──▶ backtest_failed
                      │
                      └─ 环境失效（如 2026 超额归零）──▶ 降级/禁用
```

**门槛硬约束：**
1. `backtest_failed` 的策略禁止启用，除非重新设计并通过全部关卡。
2. `conditional_pass` 的策略只能观察信号，不进核心信号融合。
3. 启用策略必须声明 `enabled_by_regime`（环境择时），弱势环境自动降权。

## 五、案例：断板反包战法的完整生命周期

| 阶段 | 动作 | 结论 |
|------|------|------|
| 规则提取 | 226 条视频转写 → 结构化规则（LLM 辅助层） | 得到形态定义 + 三买点 + 六卖出 |
| 事件研究 | 67 股 2.5 年 152 事件 | 整体负期望（5日超额 -1.5%，p=0.04） |
| Walk-Forward | rebound_elite 样本外 | 43 信号全年份负超额，证伪 |
| 抢救认知资产 | 拆解三条有效规则 | 活跃度/破位止损/板上减半 → risk_rules.py |
| 处置 | breakout_rebound / rebound_elite / fanbao 禁用 | 永不启用 |
| 观察 | rebound_system 买点A优化四条件 | +3.78% p=0.0504 N=41，前向验证中 |

**教训（已写入代码/文档）：**
- 手册字面经验值只能参考，只有数据验证过的判据才能做硬过滤。
- 一字板/天地板假阳/二波异动是形态识别的经典陷阱，必须用实体方向判定。
- 用户截图核验是最高效的 bug 发现通道，比任何回测指标都直接。

## 六、新策略上线 Checklist

- [ ] 规则来源可追溯（转写/研报/书籍 + 版本）
- [ ] 代码无 `shift(-n)`，信号时刻可得（关卡 1）
- [ ] 事件研究 + Walk-Forward 样本外检验（关卡 2）
- [ ] 真实数据截图核验（关卡 3）
- [ ] `validation_gate.status` 正确设置
- [ ] 认知资产是否可复用（有则沉淀进通用组件）
- [ ] LLM 只用于提取/审计/复盘，不参与决策
- [ ] 声明 `enabled_by_regime` 环境择时
