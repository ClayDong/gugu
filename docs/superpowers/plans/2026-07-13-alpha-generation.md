# Alpha 生成计划：从规则策略到机器学习多因子模型

## 本机配置约束

- CPU: Intel i7-5650U @ 2.20GHz, 2 核 4 线程
- RAM: 8 GB
- GPU: 无
- Python: 3.14 (uv 环境)

## 技术选型

| 组件 | 选择 | 理由 |
|------|------|------|
| 机器学习框架 | LightGBM + scikit-learn | 轻量级，CPU 友好，8GB RAM 足够 |
| 深度学习 | 不引入 | 无 GPU，PyTorch 在本机不现实 |
| 因子分析 | 自研 IC/IR 分析 | 轻量，不依赖额外框架 |
| 回测 | 复用现有 BacktestEngine | 已有 A 股规则（T+1/涨跌停/印花税） |

## 目标

1. **因子 IC 分析**：26 个因子哪些有预测力？砍掉无效因子
2. **LightGBM 多因子模型**：用机器学习找因子组合的非线性 alpha
3. **因子正交化**：去除冗余因子，减少过拟合
4. **ML 策略接入**：将 ML 预测分数作为新策略注册，参与信号生成
5. **全量回测验证**：ML 策略必须通过 9 项准入门禁才能启用

## 任务分解

### Task 1: 安装依赖
- pyproject.toml 增加 scikit-learn + lightgbm
- uv sync

### Task 2: 因子 IC 分析模块
- 新建 `src/gugu/analysis/factor_ic.py`
- 计算 26 个因子的 IC（Spearman 秩相关）、IR（IC 均值/IC 标准差）
- 输出因子有效性排名
- 筛选 |IC| > 0.03 且 |IR| > 0.3 的因子

### Task 3: 因子正交化
- 对有效因子做 Gram-Schmidt 正交化或 PCA 降维
- 输出正交化后的因子矩阵
- 消除因子间高相关性

### Task 4: LightGBM 多因子模型
- 新建 `src/gugu/analysis/ml_factor.py`

### Task 5: ML 策略接入

## v4.2 优化（2026-07-14）— Train/Test Leak 修复

### 核心发现：前版本所有回测结果均被 train/test leak 污染

**第一性原理分析**：
- v1-v4.1 的 `train_global_model()` 用全部 365 天数据训练模型
- `run_ml_backtest()` 在同样的 365 天数据上回测
- 模型训练时已见过测试期的未来收益 → 预测虚高 → 回测结果不可信
- v4.1 的 5/6 门禁通过是 train/test leak 的产物，不是真实 alpha

### 修复方案

| 修改 | 实现 | 理由 |
|------|------|------|
| 时间分割训练 | `train_global_model()` 仅用前 60% 数据训练 | 模型从未见过测试期数据 |
| 时间分割评估 | `run_ml_backtest()` 仅统计后 40% 的 trades 和 equity | 真正的 out-of-sample 评估 |
| 重计算 metrics | 用 `calc_metrics()` 对测试期 equity_curve 重算 | 避免 training period 污染指标 |
| CLI 参数 | `--train-ratio 0.6` 可配置 | 支持不同分割比例验证 |

### 对抗性审查

- **副作用1**：cooldown 状态在 training period 建立后延续到 test period → 正确行为，模拟真实部署
- **副作用2**：test period 因子计算有足够历史（全量 df 传入 engine）→ 无分布偏移问题
- **副作用3**：26/50 股票在测试期 0 交易 → 高阈值 + 长冷却期在 146 天测试期过于保守

### v4.2 Out-of-Sample 回测结果（50 股 × 365 天，60% 训练 / 40% 测试）

| 指标 | v4.1 (leaked) | v4.2 (OOS) | 门禁 | 通过 |
|------|---------------|------------|------|------|
| 总交易数 | 263 | 94 | ≥100 | ❌ |
| 平均收益 | +0.51% | **-1.14%** | ≥0 | ❌ |
| 中位收益 | +0.09% | 0.00% | ≥0 | ✅ |
| 平均夏普 | -0.149 | **-0.794** | ≥0 | ❌ |
| 最大回撤 | 13.54% | 9.20% | ≤25% | ✅ |

**2/6 项通过。** 26/50 股票在测试期 0 交易，仅 6/50 盈利。

### 根因分析

1. **模型无真实预测力**：validation accuracy 75% 是 Walk-Forward 训练期内部验证，非真正 OOS
2. **阈值过高**：buy_threshold=0.66 在 OOS 数据上极少触发，26 股 0 交易
3. **冷却期过长**：cooldown_days=16 在 146 天测试期每股最多 ~9 次买入机会
4. **因子衰减**：IC 分析的因子在训练期有效，但 test period 可能已失效

### 结论

**ML 多因子策略在当前因子集和模型架构下不产生 out-of-sample alpha。**

v1-v4.1 的所有"改善"都是 train/test leak 的幻觉。修复泄漏后，策略真实表现为亏损（-1.14% avg return）。

策略保持 `enabled: false`，不影响生产环境。生产环境继续使用已通过回测验证的规则策略（box_breakout + double_yin）。

### 下一步方向（需评估是否继续 ML 路线）

1. **降低阈值测试**：buy=0.55, cooldown=5 → 验证是否有任何 OOS 信号
2. **简化模型**：用 logistic regression 替代 LightGBM → 减少过拟合
3. **滚动重训练**：每 30 天重训练模型 → 适应因子衰减
4. **扩展因子集**：加入基本面因子（PE/PB/ROE）和情绪因子 → 提升 IC
5. **或放弃 ML 路线**：聚焦规则策略优化，承认当前因子集不足以支撑 ML alpha

| 最大回撤 | 9.2% | **29.0%** | ≤25% |
| 盈利比 | 12% | **16%** | ≥50% |
| 门禁通过 | 2/6 | **1/6** | - |

**结论**：宽松阈值产生更多交易但亏损更大。8/50 盈利（16%），34/50 亏损。
模型无 OOS 预测力：收紧阈值→交易不足，放宽阈值→噪声交易侵蚀收益。

### 最终结论

**ML 多因子策略在当前因子集（26 个技术指标）和 LightGBM 架构下不产生 out-of-sample alpha。**

v1-v4.1 的所有"改善"都是 train/test leak 的幻觉。v4.2 修复泄漏后，无论严格还是宽松阈值，策略 OOS 表现均为亏损。

**策略保持 `enabled: false`。** 生产环境继续使用已通过回测验证的规则策略（box_breakout + double_yin）。

### 要让 ML 产生 alpha，需要根本性改变

1. **扩展因子集**：当前 26 个因子全是技术指标，IC 分析显示因子方向为反向（负 IC），说明它们更适合做择时而非选股。需要加入：
   - 基本面因子：PE/PB/ROE/营收增长/利润率
   - 资金面因子：主力净流入/北向资金/融资融券
   - 情绪面因子：换手率变化/涨停板分析/板块轮动
2. **改变预测目标**：从 per-stock binary classification 改为 cross-sectional ranking（横截面排序），买入预测排名前 10% 的股票
3. **滚动重训练**：因子关系随时间变化，模型需要定期更新
4. **更大数据量**：50 股 × 365 天不够，至少需要 300 股 × 750 天

## 阶段二：深化规则策略（box_breakout v2 优化）

ML 路径证伪后，转向深化已通过回测验证的规则策略。通过对抗性审查发现 box_breakout 存在 3 个关键问题并修复。

### 对抗性审查发现

从量化研究员、风控经理、交易员三个视角审查 box_breakout v1 代码：

1. **卖出信号要求量能确认（致命 bug）**
   - 原逻辑：卖出信号需要 `volume > vol_ma * 1.5`
   - 第一性原理违反：卖出是风控动作，不应依赖量能配合
   - 实际后果：阴跌时量能萎缩，卖出信号永远不触发，持仓一路亏损无法退出
   - 典型案例：000831 v1 产生 19 笔交易亏损 -27.26%

2. **无趋势过滤**
   - 原逻辑：任何箱体突破都买入，完全依赖外部 MarketFilter
   - 第一性原理违反：箱体突破在上升趋势中有效（顺势追涨），在下降趋势中是假突破陷阱（逆势抄底）
   - 实际后果：在下跌趋势中频繁假突破，产生大量亏损交易

3. **无最大持仓天数**
   - 原逻辑：只有跌破箱体下沿才卖出
   - 第一性原理违反：突破后若趋势未如期发展，应退出等待下一个机会
   - 实际后果：资金被横盘股套牢，机会成本高昂

### v2 优化实施

修改文件：
- `src/gugu/strategies/breakout.py`：3 项修复
- `config/strategy_defaults.yaml`：新增 v2 参数

优化内容：
1. **卖出信号不再要求量能确认** — 修复阴跌无法止损的致命 bug
2. **新增趋势过滤**：MA20 > MA60 时才允许买入 — 过滤下跌趋势中的假突破
3. **新增最大持仓天数**：30天超时强制卖出 — 防止资金被横盘股套牢

### A/B 回测验证（50股 × 365天）

三组对照实验隔离每项优化的贡献：

| 指标 | v1(卖出修复+无趋势+无持仓限制) | v2_NT(+持仓30天) | v2(全优化) |
|------|-------------------------------|-------------------|-------------|
| 有交易股票数 | 49 | 49 | 37 |
| 总交易数 | 426 | 464 | **191** (-55%) |
| 平均收益 | -2.14% | -0.50% | **+0.17%** |
| 中位收益 | -4.84% | -4.01% | -0.39% |
| 平均夏普 | -0.67 | -0.62 | **-0.39** |
| 最大回撤 | 36.00% | 33.44% | **31.91%** |
| 盈利比 | 20% | 32% | 24% |

### 对抗性评估

**v2 是明显改进**：
- 平均收益从 -2.14% 转正至 +0.17%（+2.31pp）
- 夏普从 -0.67 改善至 -0.39（+0.28）
- 最大回撤从 36% 降至 31.91%（-4.09pp）
- 趋势过滤将交易数砍半（426 → 191），有效过滤下跌趋势中的假突破
- 13 只股票从亏损转为 0 交易（资金保全）

**但 v2 尚未独立产生 alpha**：
- 中位数仍为负（-0.39%），说明少数大赢家（000657 +63.84%、000823 +32.84%）拉高了均值
- 夏普仍为负（-0.39），风险调整后仍亏损
- 盈利比仅 24%，不足 50% 门禁要求
- 回测引擎未按市场状态过滤，包含熊市/震荡市交易（生产环境有 MarketFilter 拦截）

**结论**：v2 优化方向正确，各项修复均有实证贡献。策略仍需 MarketFilter 在非牛市拦截信号，与 v0.4.2 回测结论一致（box_breakout 仅在牛市有效）。下一步需全市场大样本（200+股）验证统计显著性。

### 99 股大样本验证

扩大样本至全部可用缓存（99 股 × 365 天），消除小样本幸存者偏差：

**A/B 对比（99 股）**：

| 指标 | v1 | v2_NT | v2 |
|------|-----|-------|-----|
| 总交易数 | 873 | 947 | 370 (-58%) |
| 平均收益 | -4.74% | -2.08% | -0.97% |
| 中位收益 | -7.17% | -5.10% | -1.71% |
| 平均夏普 | -0.73 | -0.61 | -0.50 |
| 盈利比 | 19.2% | 28.3% | 19.2% |

**双策略离线回测（99 股）**：

| 策略 | 平均收益 | 中位收益 | 夏普 | 最大回撤 | 胜率 | 盈利比 | 平均持仓天 |
|------|---------|---------|------|---------|------|--------|-----------|
| double_yin | -0.90% | -1.65% | -0.68 | 5.45% | 28.0% | 24% | 6.1 |
| box_breakout v2 | -1.64% | -1.71% | -0.52 | 8.45% | 19.2% | 18% | 14.5 |

### 大样本结论

1. **v2 优化在大样本下仍有效**：box_breakout 从 v1 的 -4.74% 改善至 -0.97%（+3.77pp），但 50 股的 +0.17% 正收益回归为负，说明小样本结果受少数大赢家影响
2. **两个策略均未独立产生 alpha**：在无市场状态过滤的回测中，两个策略均为负收益
3. **double_yin 比 box_breakout 更稳健**：更低回撤（5.45% vs 8.45%）、更高胜率（28% vs 19.2%）、更短持仓（6.1 vs 14.5 天）
4. **策略依赖 MarketFilter**：回测引擎未按 bar 应用 MarketFilter，结果代表全市场条件（含熊市/震荡市）。生产环境 MarketFilter 会在非牛市拦截大部分信号
5. **与 v0.4.2/v0.4.5 回测一致**：box_breakout 仅在牛市有效（+31.20%/夏普0.30），double_yin 在 50 股+3.90% 但 100 股转负

**最终结论**：box_breakout v2 优化是正确方向（显著减少亏损），但两个规则策略本质上都是牛市/趋势策略，在非趋势市场中无效。系统的 alpha 来源不在策略本身，而在 MarketFilter 的市场状态识别能力。
